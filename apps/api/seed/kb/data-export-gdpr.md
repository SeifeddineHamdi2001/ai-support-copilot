# Data Export and GDPR Requests

How customers export their data and exercise their rights under the GDPR.

## Exporting project data

Admins can export project data at any time from Settings > Data > Export. Exports are available as CSV or
JSON and are delivered as a download link by email. The link expires after 7 days.

CSV exports from the Reports screens are limited by plan: Starter exports up to 10,000 rows per file, Pro
and above have no row limit. For larger datasets on Starter, use the JSON export or the API.

## Personal data requests (GDPR)

Any person can ask for a copy of the personal data Acme Cloud holds about them (a data subject access
request), or ask for it to be corrected or erased.

- Acme Cloud answers data subject requests within 30 days of receiving them, as required by the GDPR.
- The 30-day window can be extended by up to two further months for complex requests; the requester is
  told within the first 30 days if this happens.
- Requests are sent to privacy@acmecloud.example or through the support form. Support forwards them to the
  privacy team and must not handle them on its own.
- The requester's identity is verified before any personal data is sent.

The personal data copy is delivered as a JSON file. It is separate from the project export above, which
contains the customer's business data.

## Data processing agreement

Business and Enterprise customers can sign Acme Cloud's data processing agreement (DPA) from Settings >
Legal. All customer data is stored in the EU (Frankfurt) region.
